# LINEスタンプ制作ガイド

手元のキャラクター見本を使い、画像生成・編集からLINE Creators Market向けの申請素材まで作る手順です。静止画とアニメーションに対応します。

## はじめる

1. キャラクターの参照画像、作りたいテーマとセリフ、静止画かアニメーションかを用意します。
2. [制作手順](WORKFLOW.md)の依頼文を画像生成・編集が使える環境へ渡します。普段のモデルを選び、参照画像を添付してください。
3. 画像を目視し、必要な部分を直して文字を入れます。[提出仕様](SPEC.md)と照らしてから、Main・Tab・ZIP・申請転記表を作ります。

制作用のエージェントには [AGENTS.md](AGENTS.md) が入口になります。画像生成と編集は使っている環境のツールが担当します。

## 梱包・検査ツール

完成画像の検査やZIP化を補助するPythonツールも収録しています。利用する場合は [梱包ツールの使い方](PACKAGING.md) を参照してください。

## 公開範囲

公開するのは制作手順と汎用ツールです。利用者のキャラクター資料、原画、セリフ集、制作履歴は各自のローカルで管理してください。ライセンスは [LICENSE](LICENSE)、配布ファイルの検証用ハッシュは [PUBLIC_MANIFEST.json](PUBLIC_MANIFEST.json) にあります。
